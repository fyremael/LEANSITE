A site, proven small

This is LeanSite: a deliberately compact static site generator written in Lean 4.

It treats the site as typed data, rejects duplicate or unsafe routes, escapes generated HTML, and emits plain files that can be hosted almost anywhere.

The compiler is part of the publishing pipeline.

What it understands

  • headings and paragraphs
  • strong text, emphasis, inline code, and links
  • ordered and unordered lists
  • quotes, rules, and fenced code blocks
  • project-path deployment, including GitHub Pages
#eval LeanSite.Route.href "/notes/hello"
-- /notes/hello/

Design posture

Small core. Explicit invariants. Static output. Inspectable failure modes.
